# Changelog

- Task buddies: local task states, quiet working poses, and outfit-aware task reactions.

## 1.8.1 — 2026-10-18

First public source release. macOS only; Windows and Linux are on the roadmap.

- Fixed the extra gray frame around the macOS app icon using a native macOS contour and ICNS margins.
- Added optimized ARM64 release packaging and a compressed DMG with an Applications shortcut and SHA-256 checksum.
- Included the Halloween wardrobe: 27 seasonal poses, nine short stories, candy and magic interactions, a reminder dance, and pumpkin naps.
- Shipped 279 illustrated poses across 31 collections, with procedural motion and selected multi-frame sequences.
- Kept short proactive stories every 2–3 minutes, including in a quiet open chat, with typing and interruption guards.
- Included optional DeepSeek dialogue through OpenRouter, local chat scenes, favorites, Calm mode, and five-minute eye breaks.

The DMG is ad-hoc signed and not Apple-notarized. There are no Windows or Linux binaries in this release.
