# Changelog

## 1.11.0 — 2026-10-24

- Add OpenCode Go subscription quota: five-hour, weekly and monthly windows, local v1/v2 sign-in detection and optional Go key.
- Remove DeepSeek and OpenRouter API balance cards and connection controls.
- Add Fly a kite and Heart-step dance: six new illustrations, two animated mini-scenes, short multilingual stories and direct controls.
- Preserve cute speech above the pet and independent quota bars below, including during the new mini-scenes.

## 1.10.1

- Keep cute speech above the pet and show remaining quota in a separate lower bubble.
- Add compact provider progress bars with named windows, stale-data indicators and API credit amounts.
- Preserve head-pat replies, little stories and eye-break controls while quota refreshes independently.
- Start quota loading automatically; keep full details and connections one click away.

## 1.10.0

- Replace Chat with a Coding Plan usage panel on macOS and Windows.
- Add Codex, Claude, Grok and Cursor plan meters, and DeepSeek/OpenRouter API credit balances.
- Read-only, fixed-provider requests; encrypted API keys; five-minute refresh; account-change isolation; explicit unavailable/stale states.
- Keep pet stories, poses, Halloween outfit, eye reminders and task feedback.


## 1.9.0 — 2026-10-18

- First Windows x64 installer: shared artwork, Halloween, chat, proactive stories, drag and eye-break reminders.
- Windows local task snapshots and MCP reporting, encrypted optional AI key storage.
- Automated Windows packaged-app, installer and uninstall checks; allowlisted release resources.

- Task buddies: local task states, quiet working poses, and outfit-aware task reactions.
- Codex MCP/completion adapter, Claude Code/Cursor hooks, and Pi/OMP extensions.
- Native Grok Build hooks with turn correlation and neutral idle feedback; native dsh lifecycle plugin.
- T3 Code read-only MCP watcher with OAuth transport, project selection and silent historical baselines.
- CLI process wrapper and explicit event interface for other tools.
- Concurrent task isolation, private bounded snapshots, stale status, and interruption-aware reaction queues.
- Connection panel with setup commands and an English integration guide.

## 1.8.1 — 2026-10-18

First public source release. macOS only; Windows and Linux are on the roadmap.

- Fixed the extra gray frame around the macOS app icon using a native macOS contour and ICNS margins.
- Added optimized ARM64 release packaging and a compressed DMG with an Applications shortcut and SHA-256 checksum.
- Included the Halloween wardrobe: 27 seasonal poses, nine short stories, candy and magic interactions, a reminder dance, and pumpkin naps.
- Shipped 279 illustrated poses across 31 collections, with procedural motion and selected multi-frame sequences.
- Kept short proactive stories every 2–3 minutes, including in a quiet open chat, with typing and interruption guards.
- Included optional DeepSeek dialogue through OpenRouter, local chat scenes, favorites, Calm mode, and five-minute eye breaks.

The DMG is ad-hoc signed and not Apple-notarized. There are no Windows or Linux binaries in this release.
