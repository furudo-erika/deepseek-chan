# DeepSeek-chan 1.9.0

The first Windows version, plus coding-task companionship on macOS.

## Downloads

- **Windows 10/11 x64:** `DeepSeek-chan-1.9.0-windows-x64-setup.exe` — per-user installer, no administrator rights required.
- **macOS 26+, Apple Silicon:** `DeepSeek-chan-1.9.0-arm64.dmg` — native SwiftUI/AppKit application.
- Download the matching `.sha256` file to verify either package.

## New

- Windows desktop pet with 279 illustrated poses, Halloween outfit, dragging, local multilingual chat, proactive little stories and optional OpenRouter replies.
- Mouse-triggered eye-break timer and a visible dance in the center of the active screen. Reminders preserve unsent chat drafts.
- Task buddies: Codex MCP/completion adapter, Claude Code/Cursor/Grok hooks, Pi/OMP/dsh extensions and a read-only T3 Code watcher on macOS.
- Windows task snapshots and generic MCP reporting; native hook installers and automatic T3 observation remain macOS-only.

## Verification and limits

Windows is built on GitHub's Windows runner. Automated checks cover the packaged app and the application installed from the EXE, including startup, artwork loading, chat, costume switching, local task updates, reminder controls and draft preservation. The Mac behavior suite and release package checks also run in CI. This is not a claim of testing every Windows device or a live AI-provider session. Windows does not yet include Mac favorites or every contextual conversation routine. Linux and Windows ARM64 are not included.

The Windows installer is unsigned; the Mac app is ad-hoc signed and not Apple-notarized. Operating systems may show an unknown-publisher warning. Use the repository's release assets and checksums; do not disable system protections globally.

No API keys, personal preferences or chat logs are bundled. Supply your own OpenRouter key only if you want AI dialogue. Task reactions work locally without it.
