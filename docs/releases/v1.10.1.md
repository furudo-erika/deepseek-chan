# Deepseek Chan Desktop 1.10.1

**Cute chatter above. Quota bars below.** Both stay with your desktop pet.

- Her original speech bubble keeps cute replies, head pats and little stories.
- A separate lower bubble displays Codex, Claude, Grok and Cursor remaining quota as progress bars, plus DeepSeek and OpenRouter API credit amounts.
- Each compact bar names its most constrained returned window. **Details** opens every window, reset time and connection option.
- Quota loads automatically and refreshes every five minutes without replacing her speech. Missing accounts show a connection state; old values are labelled and greyed out.
- Windows scales the companion to fit small or highly scaled displays.
- Eye-break controls temporarily take priority, and the pet keeps a stable screen position as the layout changes.

## Downloads

- Windows 10/11 x64: **DeepSeek-chan-1.10.1-windows-x64-setup.exe**
- macOS 26+, Apple Silicon: **DeepSeek-chan-1.10.1-arm64.dmg**
- Matching `.sha256` files are included.

[Connection guide](https://github.com/furudo-erika/deepseek-chan-desktop/blob/main/docs/usage.md).

Requests remain read-only. Checking quota does not generate AI replies or consume model tokens. API credit amounts are not converted into invented percentages.

Windows checks cover simultaneous speech and quota, progress bars, pet clicks, reminder priority, and the actual installer using synthetic provider data. The Mac layout was checked locally. Provider access and endpoint availability remain account-specific.

The Windows EXE is unsigned. The Mac app is ad-hoc signed and not notarized. Operating systems may show an unknown-publisher warning. Linux and Windows ARM64 packages are not included.
