# Deepseek Chan Desktop 1.11.0

**OpenCode Go joins the Coding Plan, and two new mini-scenes bring a little breeze.**

- **OpenCode Go quota at a glance.** OpenCode now shows five-hour, weekly and monthly remaining windows in the lower bubble and the Coding Plan panel. Local OpenCode Console v1/v2 sign-ins are detected automatically; an optional Go key can be saved under **Connect OpenCode Go**.
- **A cleaner Coding Plan.** DeepSeek and OpenRouter API balance cards and their connection controls have been removed. Subscription quota is now shown for Codex, Claude, Grok, Cursor and OpenCode.
- **Fly a kite and Heart-step dance.** Six new illustrations form two three-keyframe mini-scenes, with short English, Chinese and Japanese bubbles. The catalog now has **285 illustrated poses in 32 collections**, and the classic proactive story deck grows to **50 stories**.
- **Both bubbles stay together.** Cute speech remains above the pet while the independent quota progress bars stay below her, including during the new mini-scenes.

## Verification

The release checks cover the native Mac behavior, the action catalog and frame sequences, the OpenCode credential boundary and response normalization, the Electron interface with five subscription quota cards, and the Windows installer. Local verification passed 19 Python tests, 23 JavaScript tests, native quota parsing checks, and the Electron UI checks for the new frame changes and five quota cards. The Windows workflow then installs the actual EXE, launches the installed app, and uninstalls it. The macOS build is 14.

Quota requests remain read-only. Checking quota does not generate AI replies or consume model tokens. Account names and emails are not displayed, and no credentials or personal settings are included in either package. Provider endpoints and account availability can change independently of the app.

The Windows EXE is unsigned. The Mac app is ad-hoc signed and not notarized. Windows SmartScreen or macOS Gatekeeper may show an unknown-publisher warning. Verify the download source and checksum before opening it, and do not disable system protections globally. Linux and Windows ARM64 packages are not included.
