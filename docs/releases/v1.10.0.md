# Deepseek Chan Desktop 1.10.0

**Chat becomes Coding Plan.** Keep your coding quota beside your desktop pet.

- Codex, Claude, Grok and Cursor: remaining quota, provider windows and reset times.
- DeepSeek and OpenRouter: API credit balances, clearly distinguished from subscription quotas.
- Local client sign-ins, encrypted API keys, automatic five-minute refresh and manual refresh.
- Explicit disconnected, expired, rate-limited and last-known states. Switching accounts clears previous-account values.
- Cute local stories, 279 poses, Halloween outfit, task reactions and eye-break dancing remain.

## Downloads

- Windows 10/11 x64: **DeepSeek-chan-1.10.0-windows-x64-setup.exe**
- macOS 26+, Apple Silicon: **DeepSeek-chan-1.10.0-arm64.dmg**
- Matching `.sha256` files are included.

Open **Usage** on Windows or **Coding Plan** on Mac. Sign in through each coding client's own app, or add a DeepSeek/OpenRouter key under **Connect API balance**. [Connection guide](https://github.com/furudo-erika/deepseek-chan-desktop/blob/main/docs/usage.md).

The app makes read-only usage requests; it does not generate AI replies or consume model tokens to check a balance. Credentials and account identities are not bundled or displayed. Missing provider data is not presented as zero or unlimited.

Tests cover the shared parsers, native Mac bridge, errors, account isolation and the installed Windows app using synthetic provider responses. Provider APIs may change; sign-in and access restrictions remain provider-specific. Private multi-account profiles managed by another app are not imported.

The Windows EXE is unsigned. The Mac app is ad-hoc signed and not notarized. Operating systems may show an unknown-publisher warning. Linux and Windows ARM64 packages are not included.
