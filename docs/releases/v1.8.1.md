The first public release of **DeepSeek-chan**, a playful desktop companion with gentle eye-break reminders.

### Highlights

- 279 illustrated poses in 31 collections, brought to life with procedural movement.
- A Halloween witch wardrobe with 27 seasonal poses and little stories.
- Proactive speech bubbles every two to three minutes, local dialogue, and optional DeepSeek chat through OpenRouter.
- Center-screen dances for eye breaks, draggable companion, favorites, and Calm mode.
- Updated macOS icon packaging to remove the unwanted enclosing border.

### Download

Download **DeepSeek-chan-1.8.1-arm64.dmg**, open it, and drag the app to Applications.

**Requires Apple Silicon and macOS 26 or later.** Windows and Linux support are planned; this release does not include an EXE or Linux package. Intel Macs have not been tested.

This build is ad-hoc signed, not Apple-notarized. On first launch, macOS may require approval in System Settings → Privacy & Security if you trust the download. See [Apple’s instructions](https://support.apple.com/en-us/102445).

AI chat is optional and requires your own OpenRouter API key. No API key or personal preferences are included. The AI transport was checked with mock responses; live provider behavior is not verified for this release.

### Verify the download

Keep the DMG and its `.sha256` file in the same folder, then run:

```sh
shasum -a 256 -c DeepSeek-chan-1.8.1-arm64.dmg.sha256
```
